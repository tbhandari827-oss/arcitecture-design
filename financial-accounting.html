Financial Accounting

  1. Financial Fundamental 👇

    2. Financial Fundamentals is the study of the basic concepts, components, and functions of financial accounting.

  2. Typing Master 👇

    3. Typing Master is a software program designed to help users improve their typing skills.

  3. MS Paint 👇

    4. MS Paint is a simple graphics editing program that comes pre-installed with Microsoft Windows.
    It allows users to create and edit images using basic drawing tools, such as brushes, shapes, and colors.
    MS Paint is often used for quick image edits, creating simple graphics, or adding text to images.

  4. Notepad 👇

    5. Notepad is a simple text editor included with the Windows operating system.
    It is used for creating and editing plain text files.
    Notepad is a lightweight application that does not support advanced text formatting features.

  5. Tally Erp.9 👇

    6. Tally Erp.9 is a popular accounting software used for managing financial transactions and generating reports.
