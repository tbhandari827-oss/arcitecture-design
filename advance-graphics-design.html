Advance Graphics Design

  1. Computer Fandamental 👇

    2. Computer Fundamentals is the basic knowledge of computer hardware and software.
    It covers topics like computer architecture, operating systems, and programming concepts.
    This course provides a solid foundation for understanding how computers work and how to use them effectively.

  2. Typing Master 👇

    3. Typing Master is a software application designed to improve typing skills and speed.
    It provides exercises and training modules to help users develop proper typing techniques and increase their typing efficiency.

  3. CorelDraw 👇

    4. CorelDraw is a vector graphics editor developed by Corel Corporation.
    It is used for creating and editing vector graphics, such as logos, illustrations, and charts.
    It provides a wide range of tools for designing graphics for print and digital media.

  4. MS Paint 👇

    5. MS Paint is a simple raster graphics editor included with Microsoft Windows.
    It allows users to create and edit bitmap images using a variety of drawing tools and filters.

  5. Notepad 👇

    6. Notepad is a simple text editor included with Microsoft Windows.
    It allows users to create and edit plain text files.

  6. Wordpad 👇

    7. Wordpad is a simple word processor included with Microsoft Windows.
    It allows users to create and edit formatted text files.

  7. MS Word 👇

    8. MS Word is a word processing software developed by Microsoft.
    It is used for creating and editing documents with a wide range of formatting options.

  8. Page Maker 👇

    9. Page Maker is a desktop publishing software developed by Adobe Systems.
    It is used for creating layouts for print and digital media.
    It allows users to combine text, images, and graphics to design brochures, flyers, newsletters, and other publications.

  9. Photoshop 👇

    10. Photoshop is a raster graphics editor developed by Adobe Systems.
    It is used for editing and manipulating digital images.
    It provides a wide range of tools for retouching photos, creating digital artwork, and designing graphics for print and web.

  10. Illustrator 👇

    11. Illustrator is a vector graphics editor developed by Adobe Systems.
    It is used for creating and editing vector graphics, such as logos, illustrations, and charts.
    It provides a wide range of tools for designing graphics for print and digital media.
