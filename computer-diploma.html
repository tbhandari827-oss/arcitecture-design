Computer Diploma

  1. Computer Fundamental 👇

    2. Computer Fundamentals is the study of the basic concepts, components, and functions of a computer.
    It helps users understand how a computer works, how to operate it, and how it is used in everyday life.

  2. Wordpad 👇

    3. WordPad is a basic word processing program developed by Microsoft. It is included
    with many versions of the Windows operating system. WordPad allows users to
    create, edit, format, and print text documents. It is more advanced than Notepad
    because it supports text formatting, but it has fewer features than Microsoft Word.

  3. Notepad 👇

    4. Notepad is a simple text editor included with the Windows operating system.
    It is used for creating and editing plain text files.
    Notepad is a lightweight application that does not support advanced text formatting features.

  4. Typing Master 👇

    5. Typing Master is a software program designed to help users improve their typing skills.
    It provides lessons, exercises, and games to practice typing speed and accuracy.
    Typing Master tracks progress and offers feedback to help users become more proficient typists.

  5. Paint 👇

    6. Paint is a simple graphics editing program that comes pre-installed with Microsoft Windows.
    It allows users to create and edit images using basic drawing tools, such as brushes, shapes, and colors.
    Paint is often used for quick image edits, creating simple graphics, or adding text to images.

  6. Ms Word 👇

    7. Microsoft Word is a widely used word processing software developed by Microsoft.
    It allows users to create, edit, format, and print documents.
    Microsoft Word offers a variety of features, including text formatting, spell check, grammar check,
    templates, and the ability to insert images, tables, and charts into documents.

  7. Ms Excel 👇

    8. Microsoft Excel is a spreadsheet software developed by Microsoft.
    It allows users to organize, format, and calculate data using a grid of cells arranged in rows and columns.
    Excel offers features such as formulas, functions, charts, and pivot tables, making it a powerful tool for data analysis and visualization.

  8. Ms PowerPoint 👇

    9. Microsoft PowerPoint is a presentation software developed by Microsoft.
    It allows users to create slideshows with text, images, videos, and other media elements.
    PowerPoint offers a variety of design templates, animation effects, and transition options to make presentations engaging and professional.

  9. Ms Access 👇

    10. Microsoft Access is a database management software developed by Microsoft.
    It allows users to create, manage, and analyze databases.
    Access provides a user-friendly interface for designing forms, reports, and queries to interact with database information.

  10. Internet Explorer 👇

    11. Internet Explorer is a web browser developed by Microsoft.
    It allows users to access and navigate the internet, view web pages, and interact with online content.
    Internet Explorer was widely used in the past but has been largely replaced by Microsoft Edge.

  11. Visual Basic 6.0 👇

    12. Visual Basic 6.0 is a programming language and integrated development environment (IDE) developed by Microsoft.
    It allows users to create desktop applications, web applications, and component-based applications.
    Visual Basic 6.0 provides a visual design interface for building user interfaces and supports event-driven programming.

  12. Foxpro 6.0 👇

    13. FoxPro 6.0 is a database management system developed by Fox Software.
    It allows users to create, manage, and analyze databases.
    FoxPro 6.0 provides a user-friendly interface for designing forms, reports, and queries to interact with database information.
